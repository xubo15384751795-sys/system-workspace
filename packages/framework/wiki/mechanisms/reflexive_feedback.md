# Reflexive Feedback

## 1. Definition

Reflexive feedback occurs when diagnostics, prices, funding conditions, and
actor behavior recursively change each other.

## 2. Structural Role

It can amplify `M`, contract `D`, increase `K`, or accelerate `X` realization.

## 3. Observable Traces

- spread-price feedback
- funding-price feedback
- risk model deleveraging
- policy expectation loops

## 4. Cases

- [2008 GFC](../cases/2008_GFC.md)
- [2024-08-05 yen carry stress](../cases/2024_08_05_yen_carry.md)

## 5. Rejection Gate

If event order and feedback timing do not change outcomes, reflexivity should
remain interpretive rather than core evidence.
