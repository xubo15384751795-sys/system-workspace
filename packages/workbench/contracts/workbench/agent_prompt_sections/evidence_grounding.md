## Evidence grounding (static)

When producing answers or summaries from Workbench outputs:

1. Prefer **verbatim excerpts** and **file paths** over paraphrase when stakes are high.
2. Use **short citations**; do not paste entire files unless the user explicitly asked for full text.
3. If multiple runs exist, anchor to **current** pointers under `Output/current/` and the active `run_manifest.json` when present.
4. Treat external web or live market feeds as **out of scope** unless a Harvester release explicitly admits that evidence.
