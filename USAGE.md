# Usage

## 10-Minute Workflow

```bash
./sys check
./sys open
./sys next
```

## Commands

```bash
./sys check      # current risk check
./sys evidence   # evidence indicators and provenance
./sys explain    # framework-specific structural interpretation
./sys open       # open current report
./sys next       # next actions
./sys doctor     # system health
./sys refresh    # refresh current pointers and dashboards
```

Daily users do not need to understand the internal framework first.
